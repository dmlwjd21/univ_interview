# 대입 면접 기출 자료실

고3 학생이 대학·학과·전형을 고르면 최근 5년 면접 기출을 출처와 함께 보여주는 웹앱입니다.
해마다 공개되는 공식 보고서를 깃허브 액션이 스스로 수집해 넣습니다.

---

## 어떻게 자동이 되는가

「공교육 정상화 촉진 및 선행교육 규제에 관한 특별법」 제10조에 따라,
면접·구술고사를 치른 대학은 그 해 기출문항과 출제 의도를 담은
**선행학습 영향평가 결과보고서**를 **매년 3월 31일까지** 공개해야 합니다.
서울시교육청 진로진학정보센터가 이 보고서들을 연도와 대학명만 바뀌는
규칙적인 주소로 모아 두고 있어, 크롤링 없이 바로 내려받을 수 있습니다.

매월 1일 오전 9시에 액션이 돌면서

1. 대학 목록의 모든 4년제 대학에 대해 최근 5개 학년도 보고서를 내려받고
2. 본문에서 면접 질문을 추려내
3. `data/questions.json` 에 넣고 커밋합니다.

학년도는 실행 날짜로 계산합니다. 2027년 4월이 되면 수집 범위가
2023~2027학년도로 저절로 밀립니다. 손댈 것이 없습니다.

## 설치 (30분)

### 1. 저장소 만들기

깃허브에서 새 저장소를 만들고 이 폴더의 파일을 전부 올립니다.
웹에서 `Add file` → `Upload files` 로 끌어다 놓아도 됩니다.

```
index.html                     앱 본체
data/universities.json         대학 299곳 목록
data/questions.json            수집 결과 (액션이 채움)
scripts/collect.py             수집기
.github/workflows/collect.yml  매월 1일 자동 실행
apps-script/Code.gs            구글 시트 연결기 (선택)
```

### 2. 액션에 쓰기 권한 주기

`Settings` → `Actions` → `General` → 맨 아래 **Workflow permissions** 에서
`Read and write permissions` 를 켜고 저장합니다.
이게 없으면 수집은 되는데 커밋이 막힙니다.

### 3. 페이지 켜기

`Settings` → `Pages` → Source 를 `Deploy from a branch`,
브랜치 `main` / 폴더 `/ (root)` 로 지정합니다.
몇 분 뒤 `https://아이디.github.io/저장소이름/` 에서 열립니다.
이 주소를 학생들에게 주면 됩니다.

### 4. 첫 수집 돌려보기

`Actions` 탭 → `면접 기출 수집` → `Run workflow`.
처음에는 한 대학만 넣어 확인하는 편이 낫습니다.

```
특정 대학만 시험 실행: 부산대학교
```

`data/report.json` 에 대학별 성공·실패가 남으니 그걸 보고 판단하세요.
전체 실행은 299곳 × 5개년이라 두세 시간 걸립니다.

### 5. 정리 단계 켜기 (선택, 권장)

키 없이도 돌아가지만, 규칙만으로는 보고서 서술문이 문항으로 섞여 들어옵니다.
언어모델에 한 번 걸러 주면 훨씬 깨끗해집니다.

`Settings` → `Secrets and variables` → `Actions` → `New repository secret`

| 이름 | 값 |
|---|---|
| `GEMINI_API_KEY` | 구글 AI 스튜디오에서 발급. 무료 한도로 충분합니다. |
| `ANTHROPIC_API_KEY` | 대신 이걸 넣어도 됩니다. 둘 중 하나면 됩니다. |

## 자동으로 안 되는 것

솔직하게 적어 둡니다.

- **전문대학 110곳**은 이 아카이브에 없습니다. 각 대학 입학처에 흩어져 있어
  주소 규칙이 없습니다. 앱에서는 입학처 검색 링크로 연결하고, 문항은
  아래 구글 시트로 직접 넣어야 합니다.
- **면접 후기**는 저작권이 작성자에게 있어 본문을 가져오지 않습니다.
  앱이 대학·학과에 맞는 검색어로 수만휘·네이버·구글에 보내 주고,
  읽은 것은 요약해 시트에 남기는 방식입니다.
- **입시 결과**는 대학어디가가 매년 5월경 갱신합니다. 앱에 박아 두면 금방
  틀린 값이 되므로 원자료로 보내는 것을 우선했습니다.
- **추출 정밀도**는 100%가 아닙니다. 보고서 서식이 대학마다 달라
  논술 지시문이 섞이거나 문항을 놓치는 경우가 있습니다. 5단계를 켜면
  많이 나아지지만, 중요한 대학은 원문 링크로 확인하는 편이 안전합니다.
- 아카이브 주소 체계가 바뀌면 링크가 깨집니다. 그때는
  `scripts/collect.py` 의 `ARCHIVE` 와 `index.html` 의 `ARCHIVE` 한 줄씩만
  고치면 됩니다.

## 구글 시트로 자료 모으기 (선택)

자동 수집이 놓친 것을 선생님·학생이 채워 넣는 통로입니다.

1. 구글 시트를 만들고 `확장 프로그램` → `Apps Script` 에 `apps-script/Code.gs` 를 붙입니다.
2. `프로젝트 설정` → `스크립트 속성` 에 넣습니다.

   | 이름 | 값 |
   |---|---|
   | `GITHUB_TOKEN` | 깃허브 Fine-grained 토큰, 해당 저장소 Contents 읽기/쓰기 |
   | `GITHUB_REPO` | `아이디/저장소이름` |
   | `GITHUB_BRANCH` | `main` |

3. 시트를 새로고침하면 상단에 `면접 자료` 메뉴가 생깁니다.
   `시트 형식 만들기` 로 틀을 잡고, 채운 뒤 `깃허브로 올리기` 를 누릅니다.
4. 앱이 `data/contributed.json` 을 읽어 자동 수집분과 함께 보여줍니다.

수집기가 건드리는 파일과 시트가 올리는 파일이 달라서 서로 덮어쓰지 않습니다.

## 직접 돌려보기

```bash
pip install -r scripts/requirements.txt
python scripts/collect.py --only 부산대학교 --no-refine
```

| 옵션 | 뜻 |
|---|---|
| `--years 5` | 최근 몇 개 학년도를 볼지 |
| `--only 서울대학교,부산대학교` | 특정 대학만 |
| `--no-refine` | 언어모델 정리 생략 |
| `--sleep 0.7` | 요청 간격(초) |

이미 모은 대학·학년도는 다시 내려받지 않습니다.
처음부터 다시 하려면 `data/questions.json` 을 `[]` 로 비우세요.
